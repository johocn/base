## 3. M1 适老化（主线）

### 3.1 字阶令牌

`App.vue` 全局 CSS 变量（页面样式均无 scoped，全局生效）：

```css
:root {
  --fs-annotate: 15px;  /* 标注字：辅助说明、时间、meta */
  --fs-body: 19px;      /* 大字：正文、列表项、按钮文字 */
  --fs-title: 24px;     /* 超大字：页标题、区块标题、宫格入口文字 */
}
```

配套约束：点击目标 ≥48px；行高 1.6；按钮内边距加大；去横滑手势（改纵向堆叠）；确认弹窗主按钮 ≥52px 高。

### 3.2 首页（A+B 融合）

1. 顶部：超大字页标题 + 大搜索框
2. B 宫格区：2×2 大宫格（学课程 / 看文章 / 去投稿 / 我的），大图标 + 超大字，格高 96px
3. A 瀑布区：宫格下方「最近更新」大卡流（课程/文章混合，全宽卡，大字标题 + 标注字 meta）
4. 底部：四 tab（首页/课程/投稿/我的）大图标大字

### 3.3 逐页改造（三档）

| 档 | 页面 | 改法 |
|---|---|---|
| 重排 | 首页、我的 | 新布局（§3.2） |
| 常规放大 | 课程详情、课时详情、文章、投稿、设置等高频页 | 字阶变量替换 + 按钮/tab/弹窗尺寸约束，结构不动 |
| 批量过 | 其余列表/表单页 | 字阶变量统一替换，抽查 |

### 3.4 富文本与字阶关系

正文渲染基准字号抬到大字档（19px）；`[文字]{.fs-sm/lg/xl}` 标签在基准之上相对生效（既有 #83 渲染器语义不变）。

## 4. M2 私有笔记（独立模块）

- 新内容类型 `note`：**不上节点 catalog、不进事件流、不入台账**，仅本机 repo 存储（新本地表）；换机不迁移（预期行为，指引中说明）
- 页面：笔记列表（大字 + 标签过滤）+ 编辑器（复用现有 Markdown 编辑组件与图库）+ 详情
- 入口：「我的」页新增「我的笔记」项；首页宫格不占位（四宫格已定）
- 隐私边界：任何提交/同步/目录路径不得引用 note；core 层 submit 链路对 note 类型短路

## 5. M3 评论补全（增量）

- 课程详情页补评论入口与列表（同构文章页既有实现：`pages/comment/comment.vue` + `core/comment.ts`）
- 全部评论 UI 过适老字阶（标注/大字映射）
- 协议零改动（comment.v1 既有）

## 6. M4 圈子（完整原方案）

协议、数据、算法**全部按 `2026-09-29-base-governance-circle-design.md` 实现**（该册子为准，本册不复制）：

- 双形态：开放圈（明文/匿名可读/自助加入）/ 封闭圈（AEAD/成员签名读权/邀请码带密钥）
- 席位阶梯 k(m)、贡献度排名 9 条规则、决议规则与门槛、治理提案投票

本轮新增 **mobile 端 UI 层**：

1. 建圈向导（选形态：公开/邀请，定死提示）
2. 圈子列表 / 圈子详情（成员、席位、贡献度展示）
3. 圈内内容发布与只读流（明文/密文分支）
4. 邀请码签发（在册成员）与使用（加入封闭圈）
5. 治理页：提案列表/发起提案/投票（按原册子门槛）

入口：「我的」页 + 首页宫格不占位（圈子列表从「我的」进，M5 指引引导发现）。

1. **圈子完整原方案工程量最大**（算法 9 条 + 治理协议 + UI 六页）：按原册子逐节 TDD，排名算法用向量测试锁定（原册子 §3.3 已含验收断言样例）
