## 1. 需求（用户原文归纳）

1. 底部导航去评论，改：课程 / 圈子 / 文章 / 我的
2. 首页宫格大图标改：必修 / 选修 / 精品 / 文章 / 评论，之后继续按序排具体课程分类（从零开始、深度学习…），每行 3 个
3. 课程列表按 置顶/加精/推荐/正常 排序，20 条；文章 20 条；公开圈子 20 条
4. 公告放最上面，多条滚动，圈子页同样
5. 细节参照 Discuz 论坛；适老底座（字阶/点击目标）不变
6. 首页数据走节点数据（方案 B：同步镜像展示，零协议改动）；本地数据操作统一移到「我的」

## 3. 设计决策（用户确认）

| # | 决策 | 结论 |
|---|---|---|

## 4. 方案

### 4.1 tabBar（pages.json）

课程 / 圈子 / 文章 / 我的。「文章」tab → `pages/search/search`（页标题改「文章」）；评论 tab 移除，评论页路由保留（入口=首页宫格「评论」+课程/文章详情既有入口）。

### 4.2 首页（course.vue 重排，自上而下）

1. **公告条**：「公告」标签 + 生效公告多条竖向轮播（3s/条，CSS animation 轮换），无公告隐藏。数据=本机 govern 决议流中 announcement 类型且已生效的提案文本（生效列表存 config `announcements_active`）
2. **大图标网格**：每行 3 个（`grid-template-columns: repeat(3,1fr)`）：必修 / 选修 / 精品 / 文章 / 评论，之后动态续排 term 分类（从零开始/深度学习…，数据源 groupCoursesByCategory 既有分类），末位「更多分类」
3. **操作行移除**：同步/新建课程/我创建的 → 移「我的」页（§4.5）
4. **课程列表 20 条**：平铺卡片 + 角标（置顶红/加精橙/推荐蓝/正常无标）
5. **文章区 20 条**：区头「精选文章」+ 文章卡（加精角标+标题+meta）
6. **公开圈子区 20 条**：区头「公开圈子」+ 圈子行（圈名+形态标注+成员数）

### 4.3 角标本地规则

| 角标 | 映射 | 排序权重 |
|---|---|---|
| 置顶（红） | 必修类课程 | 1 |
| 加精（橙） | 精品类课程/文章 | 2 |
| 推荐（蓝） | 7 天内有更新（updated_at） | 3 |
| 正常 | 其余 | 4 |

同权重内按 updated_at 倒序；各列表截 20 条。

### 4.4 公告票选链路

- `govern.ts` 提案类型枚举扩 `announcement`（正文=公告文本）
- governance.vue 新增「发起公告提案」入口（大字表单：公告文本）
- 投票复用既有 governance.vue 两阶段 UI；达门槛生效 → 写 config `announcements_active`（JSON 数组，上限 10 条）
- 首页 + 圈子页（group.vue）顶部读同一 config 渲染轮播；失效公告由新决议（撤销类）移除——一期简化：生效列表手动按决议内容更新，撤销链路挂账

### 4.5 我的页接收本地操作

菜单区「创作」组内加三项大行入口：**同步数据**（原首页同步按钮逻辑迁移）、**新建课程**、**我创建的**（列表页复用既有 my-created 视图）。首页不再出现本地操作。

## 5. 边界与预期行为

| 场景 | 行为 |
|---|---|
| 未同步过（本机无 catalog） | 首页各列表空态提示「下拉同步后可见」，公告条隐藏 |
| 分类点击 | 进筛选列表页（复用列表形态，按分类过滤 20 条） |
| 评论 tab 移除后 | 评论页仍可从首页宫格、课程/文章详情进入 |
| 公告未通过投票 | 不展示（只有生效决议进 config） |
| 圈子页公告 | 与首页同一数据源同一组件形态 |

## 6. 挂账（二期）
