## 0. 执行口径

- **执行环境**：App 侧须**真机**（飞行模式、附件落盘、系统打开等行为模拟器不可信）；C 组须**部署机**（能 `ssh me`）；D 组为**本机**。
- **通用前置**：先完成手册 #42 §1 的 1.1–1.5（安装 → 节点地址与公钥 → 基座自检四项「有」含升级验签 → 课程同步 → 我的条目是否为空）。
- **A 组关键前提**：编辑入口只在**本人建的容器**上出现（A6 验）。导入器域（随内容包同步下来的）课程 / 课时**全程只读**，其改动归 #27 提案线，不在本册。
- **结论取值**：`PASS` / `FAIL` / `BLOCKED` / `NA`。
  - `FAIL` 必须附：设备型号 + 系统版本 + App 版本 + 复现步骤 + 截图或日志 + 是否可稳定复现。
  - `BLOCKED` 必须写清卡点（如缺第二节点、缺 md 源、缺部署机）。
  - `NA` 仅用于确实不适用（如 A11 无第二节点时改判 BLOCKED，不用 NA）。
- **交付判定**：**A 组与 D 组都必须跑完**（D 组可一键复跑：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/acceptance-d.ps1`）；B 组全站回归须全跑；C 组至少跑 C1。
